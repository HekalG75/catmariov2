# Cat Mario V2 🐱

Game platformer bergaya Cat Mario yang bisa dimainkan langsung di browser!

## 🎮 Tentang Game

Cat Mario V2 adalah game platformer yang menantang dengan berbagai rintangan dan musuh. Game ini dibuat menggunakan HTML5 Canvas dan JavaScript murni.

## 🚀 Cara Bermain

1. Clone repository ini:
   ```bash
   git clone https://github.com/USERNAME/catmario-v2.git
   ```

2. Buka file `index.html` di browser Anda

3. Atau kunjungi versi online di: [https://hekalg75.github.io/catmariov2/]

## 🎯 Kontrol

- **Arrow Keys / WASD**: Gerakkan karakter
- **Space**: Lompat
- **R**: Restart level

## 🛠️ Teknologi

- HTML5 Canvas
- JavaScript (Vanilla)
- CSS3

## 📁 Struktur Proyek

```
catmariov2/
├── index.html          # File HTML utama
├── style.css           # Styling game
├── game.js             # Logic game utama
├── player.js           # Logic player
├── gameObjects.js      # Objek-objek game
├── levelConfig.js      # Konfigurasi level
└── assets/             # Asset gambar dan audio
```
